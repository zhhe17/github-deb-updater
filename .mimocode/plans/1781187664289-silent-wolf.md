# GitHub deb 软件更新工具 - Web 界面实现计划

## 概述

将现有的 bash 脚本工具完全重写为 **Python FastAPI + 服务端渲染** 的 Web 应用，保留核心功能并提供美观的 Web 管理界面。

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | Python 3.10+ + FastAPI | 异步 Web 框架，自动生成 API 文档 |
| 前端 | Jinja2 + Tailwind CSS + Alpine.js | 服务端渲染，轻量交互 |
| 配置 | YAML (PyYAML) | 保持与现有 packages.yaml 兼容 |
| HTTP 客户端 | httpx | 异步请求 GitHub API |
| 版本比较 | packaging | Python 标准版本比较库 |
| 进程管理 | systemd | 以 root 权限运行 Web 服务 |

## 核心功能模块

### 1. GitHub API 服务 (`app/services/github.py`)

重写 `lib/github.sh` 的核心逻辑：
- `get_latest_release(repo)` -> 返回版本号和资产列表
- `get_asset_url(repo, pattern)` -> 返回下载链接
- 异步并发检查多个仓库
- 自动重试和速率限制处理
- Token 认证支持

### 2. 版本服务 (`app/services/version.py`)

重写 `lib/version.sh` 的核心逻辑：
- `get_installed_version(name)` -> 调用 `dpkg -l` 查询
- `normalize_version(version)` -> 去除构建元数据
- `compare_versions(a, b)` -> 使用 `packaging.version.Version`
- `is_update_needed(installed, latest)` -> 判断是否需要更新

### 3. 安装服务 (`app/services/installer.py`)

重写 `lib/installer.sh` 的核心逻辑：
- `download_deb(url, name, version)` -> 下载到缓存目录
- `install_deb(path, pre_cmd, post_cmd)` -> 调用 `dpkg -i`
- 异步下载，支持进度反馈（WebSocket 或 SSE）
- 缓存管理和清理

### 4. Web 界面

**首页 - 软件列表**
- 卡片式展示所有软件包
- 显示：名称、本地版本、最新版本、状态（最新/可更新/未安装）
- 一键更新按钮
- 批量更新功能

**软件详情页**
- 版本历史
- 更新日志（从 GitHub Release 获取）
- 手动指定版本安装

**设置页面**
- GitHub Token 配置
- 软件包管理（增删改）
- 缓存管理

### 5. 后台任务

- 定时检查更新（可配置间隔）
- 更新检查结果缓存
- 异步安装任务队列

## 验证方式

### 功能测试
1. 启动服务：`uvicorn app.main:app --host 0.0.0.0 --port 8000`
2. 访问 http://localhost:8000 查看软件列表
3. 测试单个软件更新：点击更新按钮
4. 测试批量更新：选择多个软件
5. 测试设置页面：配置 Token、添加软件包

### API 测试
- 访问 http://localhost:8000/docs 查看自动生成的 API 文档
- 使用 curl 或 httpie 测试 API 端点

### 集成测试
- 测试 GitHub API 调用
- 测试版本比较逻辑
- 测试下载和安装流程（可在测试环境用 mock）

## 注意事项

1. **权限问题**：Web 服务需要以 root 或有 sudo 权限的用户运行
2. **安全性**：Token 存储在 config.yaml 中，注意文件权限
3. **并发控制**：同时只能执行一个安装任务
4. **错误处理**：网络错误、下载失败、安装失败都需要友好提示
5. **日志记录**：保留日志功能，方便调试
